Mosaico Studio v4

Arquivos: index.html (HTML + CSS + JS em arquivo único), manifest.json, sw.js, ícones.

Principais mudanças:
- Canvas livre: fotos e adesivos são objetos arrastáveis por toque ou mouse.
- Lixeira flutuante: arraste um item até ela para apagar.
- Barra de controles fora das imagens: apagar, aumentar, diminuir, ajustar/preencher, duplicar e ordem.
- Molduras, adesivos e fundos em menu flutuante lateral direito.
- Adesivos com busca via Iconify/OpenMoji e fallback visual por emoji.
- Layouts rápidos no menu inferior do mobile.
- Pesquisa de imagens até 100 resultados, idioma detectado pelo navegador e expansão de termos em português do Brasil.
- IndexedDB para salvar o projeto localmente.
- Exportação PNG e impressão A4.

Teste local: python -m http.server 8080 e abra http://localhost:8080/ .
